# Portfolio — Oussama EL AYOUCHI

Portfolio professionnel construit avec Next.js.

## Positionnement

Ingénieur systèmes embarqués & Safety, actuellement en reconversion vers la Data Analyse.

Le site présente :
- parcours et expériences professionnelles ;
- projets techniques ;
- reconversion Data (SQL, Power BI, Python, Excel) ;
- diplômes ;
- certifications ;
- centres d’intérêt ;
- contact.

## Lancer le projet

```bash
npm install
npm run dev
```

Puis ouvrir `http://localhost:3000`.

## Déploiement

Le projet est compatible avec Vercel : importer simplement ce dépôt depuis le tableau de bord Vercel.

## Stack

Next.js · React · CSS
